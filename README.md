# محمد إبراهيم - Media AI
Landing page احترافية RTL باللغة العربية، بتصميم أسود + ذهبي.

## الملفات
- `index.html` الصفحة الرئيسية
- `style.css` التصميم والاستجابة للموبايل
- `script.js` التفاعلات البسيطة
- `assets/` ضع فيها صور أعمالك ولوجو البراند
- `README.md` تعليمات المشروع

## التعديل
افتح `index.html` لتغيير النصوص والروابط، و`style.css` لتغيير الألوان والتصميم.
صور الأعمال يمكن وضعها داخل `assets` ثم استبدال عناصر `project-placeholder` بصور حقيقية.

## النشر
المشروع Static، ويمكن نشره على GitHub Pages أو أي استضافة تدعم HTML/CSS/JS.
